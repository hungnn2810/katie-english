# Phase 3 — UI Design Contract: Teacher Dashboard

> Visual and interaction contract for the Teacher Dashboard phase. Generated by gsd-ui-researcher as a retroactive contract documenting actual implemented decisions.
> Covers: TypePickerModal entry point, Reading homework creation page (matching + fill-in-blank + DnD), submission count display, reading session result review, sessions list page.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no shadcn/ui — custom Tailwind component classes) |
| Preset | not applicable |
| Component library | none (hand-built components) |
| Icon library | none — inline SVGs throughout (no lucide, heroicons, etc.) |
| Font | Inter (Google Fonts via `next/font/google`, variable `--font-inter`) |

**Note (source: CONTEXT.md D-19 through D-23):** Phase 3 plans 08+ planned shadcn/ui initialization with Zinc base theme. Plans 01–07 (executed) predated this and use the existing hand-built Tailwind system. This contract documents the plans 01–07 implementation only.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding (`px-1`, `py-0.5`) |
| sm | 8px | Compact element spacing, modal header bottom padding |
| md | 16px | Default element spacing, card padding base |
| lg | 24px | Section padding, modal horizontal padding (`px-6`) |
| xl | 32px | Layout gaps, page content padding (`px-8`) |
| 2xl | 48px | Major section breaks (creation page `py-12` empty state) |
| 3xl | 64px | Page-level empty state vertical padding (`py-20`) |

Exceptions:
- Sidebar width: fixed `w-64` (256px) — desktop-only shell, no collapsible (source: D-25)
- Shell minimum width: 1280px enforced via inline `minWidth: 1280` on root div (source: codebase, TeacherShell.tsx)
- Card content padding: `p-5` (20px) — actual measured value in card components
- Activity card header: `px-5 py-3` (20px / 12px) — deliberate asymmetric for compact header strip

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.5 | Card content, form labels, list rows, modal body text |
| Label | 12px (`text-xs`) | 700 (bold) | 1.4 | Section headers, uppercase tracking labels (`uppercase tracking-wide`), badge text |
| Heading | 18px (`text-lg`) | 700 (bold) | 1.2 | Page header title in TeacherShell (`font-bold`) |
| Display | 24px (`text-2xl`) | 900 (`font-black`) | 1.1 | Reading creation page main heading; modal primary headings use `text-lg font-black` |

Exceptions:
- Score display on session detail: 30px (`text-3xl`) `font-black` — deliberate oversized for at-a-glance score
- Sidebar brand name: 15px (`text-[15px]`) `font-bold` — fractional size preserved from existing shell
- Sidebar sub-label ("Teacher Portal"): 11px (`text-[11px]`) — deliberate small label
- Activity section labels (uppercase): 12px `font-bold uppercase tracking-wide` — all-caps section dividers

## Interaction Contracts

### TypePickerModal
- Opens when teacher clicks "+ Create" on homework list
- Displays 3 type cards (Phonics, Speaking, Reading) in a 3-column grid
- Each card: `py-5` tall, `text-2xl` emoji + type label, `border-2` with type color at 33% opacity
- Hover: `scale-105` + `shadow-md`
- PHONICS / SPEAKING: closes TypePickerModal, opens HomeworkModal
- READING: navigates to `/teacher/homework/create/reading`
- Click outside overlay closes modal

### Reading Creation Page
- Layout: `max-w-3xl mx-auto px-8 py-8`, inside `TeacherShell`
- Name input: `.input-base` with uppercase label + validation error on save attempt
- DnD reorder: `@dnd-kit/sortable` with `PointerSensor` (activationConstraint: distance 4px) + `KeyboardSensor`
- Drag handle: hamburger icon (3-line SVG), `cursor-grab active:cursor-grabbing`
- Dragging item: `opacity: 0.6` visual feedback
- Activity card header strip: `bg-background/50 border-b border-border` with type badge + "Activity N" counter + Remove button
- Empty activities state: dashed border `border-dashed border-border bg-background/50 py-12` centered message
- Add activity row: two dashed-border buttons (`border-dashed`), secondary color for Matching, accent/amber for Fill-in-blank
- Save button: disabled + spinner during API call; redirects to `/teacher/homework` on success (D-03)

### Matching Activity Editor
- Grid: `grid-cols-3 gap-3`
- Pair card: `bg-background rounded-xl border border-border p-3`
- Image: 80×80px (`w-20 h-20`) rounded-lg object-cover
- Empty image slot: dashed border upload zone with 🖼️ emoji, `hover:bg-secondary/10`
- Uploading: spinner replaces emoji
- Word input: `.input-base text-sm py-2`
- Remove button: `✕` text, `text-highlight hover:text-red-600`
- Limit display: "N / 6 pairs" counter + "Maximum 6 pairs reached" when at limit
- Min validation warning: "Add at least 2 image-word pairs." in `text-highlight` when count = 1

### Fill-in-Blank Activity Editor
- Sentence input: `input-base` textarea (type="text") at top
- Tokenized chip row: `flex flex-wrap gap-1.5` after tokenization
- Word token (not blank): `bg-gray-100 text-textPrimary px-2.5 py-1 rounded-lg text-sm hover:bg-primary/10 cursor-pointer`
- Word token (blank): `bg-primary text-white px-2.5 py-1 rounded-lg text-sm font-semibold` with "×" remove indicator
- Whitespace token: `inline-block w-2` (non-interactive spacer)
- Click word token: toggles blank state
- Distractor row per blank: `Blank N: "word"` label (monospace, `text-xs`) + comma-separated input
- Validation: at least 1 distractor required per blank

### Submission Count Display
- Homework list card: "N/M submitted" shown as `text-xs font-semibold` inline text (not a badge)
- Denominator M: sum of enrolled students across all assignment classes (D-13)

### Session Detail — Reading Results Section
- Section heading: "Reading Results" `text-base font-bold text-textPrimary`
- Activity cards: `bg-white border border-border rounded-2xl shadow-sm`, stacked with `space-y-3`
- Card header: full-width button row, `px-5 py-3`, with activity label + score + expand chevron (▸/▾)
- Expand state: `border-t border-border px-5 py-3` content area, `divide-y divide-border/50` row separator
- Image thumbnail in MatchingResultRow: `w-10 h-10 rounded-lg object-cover border border-border` (40×40px, source: RESEARCH.md Claude's Discretion)
- Score display: `font-bold text-sm` with `scoreHex()` inline style (green/amber/red by threshold)

### Sessions List Page
- Filter row: `bg-white rounded-2xl border border-border p-4 flex flex-wrap gap-3` with Student and Assignment dropdowns + Search button
- Session rows: expandable list, chevron toggle, expand fetches session detail on-demand
- ScoreBadge: `px-2 py-0.5 rounded-full text-xs font-bold` — green (≥80%), yellow (≥50%), red (<50%)
