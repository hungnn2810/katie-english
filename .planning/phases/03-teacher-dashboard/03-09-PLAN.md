# Phase 3 Plan 09 — Create Homework UI/UX Upgrade

**Phase:** 3 — Teacher Dashboard
**Wave:** 9
**Status:** pending

---

## Goal

Upgrade the Create Homework flow from a clunky two-step TypePickerModal → HomeworkModal into a single polished modal. Align sizing/spacing with classes and students modals. Improve PHONICS form UX with collapsible parts and cleaner word entry. Upgrade AssignModal to match.

---

## Context

### Current problems
- Two separate dialogs (TypePickerModal → HomeworkModal) — extra click, jarring transition
- HomeworkModal `max-w-xl` too narrow for PHONICS with many parts/words
- Old padding `px-6 py-5` inconsistent with upgraded classes/students (`px-8 py-6`)
- No type-colored heading highlight (other modals have this pattern)
- PHONICS parts always expanded — vertical overflow with 3+ parts
- Word entry row cramped — add-word button not prominent
- AssignModal `max-w-md` with old padding

### Target state
- One "New Homework" click → single `max-w-2xl` modal opens
- Type selector at top; selecting READING shows a redirect button instead of form
- Heading dynamically shows type color: **"New · [TypeColor]Phonics"**
- PHONICS parts collapsible (collapsed by default when ≥ 2 parts)
- Word entry row with full-width input + prominent Add button
- AssignModal: `max-w-2xl`, `px-8 py-6`, highlighted heading

---

## Tasks

### T1 — Delete TypePickerModal, wire "New Homework" directly to HomeworkModal
**File:** `frontend/app/teacher/homework/page.tsx`

- Remove `showTypePicker` state
- `openCreate()` → `setShowModal(true)` (form resets to `emptyForm()`)
- Remove TypePickerModal rendering from JSX

### T2 — HomeworkModal: size, padding, header upgrade
**File:** `frontend/app/teacher/homework/page.tsx` — `HomeworkModal`

- `DialogContent`: `max-w-xl` → `max-w-2xl`; keep `max-h-[90vh] overflow-y-auto`
- `DialogHeader`: `px-6 pt-6 pb-4` → `px-8 pt-7 pb-5`
- `DialogTitle`: `text-lg` → `text-xl`; change to dynamic highlight:
  - Creating: `"New · "` (muted) + type label in `meta.color`
  - Editing: `"Edit · "` (muted) + homework name in `meta.color` (fallback to type label)
- Form body: `px-6 py-5 space-y-5` → `px-8 py-6 space-y-6`
- Footer: `px-6 pb-6 pt-4` → `px-8 pb-7 pt-5`
- Type grid `gap-3` → `gap-4`; card `py-3` → `py-4`; add type icon above label (vertical layout)

### T3 — READING redirect block in HomeworkModal
**File:** `frontend/app/teacher/homework/page.tsx` — `HomeworkModal`

When `form.type === 'READING'` and `editingId === null`, render a call-to-action block instead of the form body:
```
┌──────────────────────────────────────────┐
│  [BookOpen icon]                         │
│  Reading homework uses a dedicated editor│
│  [→ Open Reading Editor] button          │
└──────────────────────────────────────────┘
```
- Button navigates to `/teacher/homework/create/reading` and closes modal
- Import `useRouter` (already present) for navigation

### T4 — PHONICS: collapsible parts
**File:** `frontend/app/teacher/homework/page.tsx` — `HomeworkModal` PHONICS section

- Add `collapsedParts` state: `Set<number>` — parts ≥ index 1 start collapsed
- Each part card header: add collapse toggle button (ChevronDown/ChevronRight icon)
- When collapsed: show only the part header row (Part N badge + name + word count chip + expand button)
- When expanded: show full word list + add-word row
- First part (index 0) starts expanded; others start collapsed when part count ≥ 2

### T5 — PHONICS: better word entry row
**File:** `frontend/app/teacher/homework/page.tsx` — `HomeworkModal` PHONICS section

Current add-word row: two small inline inputs + small button (cramped).

Replace with:
- Single-row: `[Word text input flex-1] [Highlight input w-28] [+ Add Word button]`
- `+ Add Word` button: solid `meta.color` bg, white text, `px-4 py-2 h-auto rounded-xl font-bold`
- On Enter key in word text input: trigger addWord (already exists — keep)
- Hint text under row: `"Press Enter to add quickly"`
- Word rows in list: use `gap-3` instead of `gap-2`, slightly taller (`py-2.5`)

### T6 — AssignModal: size, padding, heading upgrade
**File:** `frontend/app/teacher/homework/page.tsx` — `AssignModal`

- `DialogTitle`: `text-lg` → `text-xl`; change to:

- Footer: `px-6 pb-6` → `px-8 pb-7`

## Acceptance Criteria

1. Clicking "New Homework" opens one modal directly — no intermediate TypePickerModal
2. Selecting READING type shows redirect block; clicking it navigates to reading creation
3. Selecting PHONICS/SPEAKING shows form immediately in same modal
4. Modal heading shows type-colored label in all create/edit cases
5. PHONICS modal with 3+ parts: parts 2+ start collapsed; clicking header expands
6. Word add row: Enter key adds word; hint "Press Enter to add quickly" visible
7. AssignModal is `max-w-2xl` with `px-8` padding and highlighted heading
8. `npx tsc --noEmit` passes with no errors
