Each card header shows the activity type + score + chevron; clicking expands the per-item rows. Matching rows show image thumbnail + student's chosen word + correct/wrong badge. Fill-in-blank rows show the full sentence with the student's chosen word substituted inline, colored green or red based on correctness.
