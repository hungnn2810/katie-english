<objective>
Build the backend slice for VOCABULARY homework end-to-end: CRUD endpoints to create/read/update
vocab homework (image-word items, up to 10, ordered), a game endpoint that scores a single recorded
vocab word through the existing BFA `analyze` pipeline (per D-03), result storage in
`PhonicsItemResult` keyed by `vocabItemId` (per D-04), and a `completeSession` VOCABULARY branch.

Purpose: This is the vertical-slice backbone. After this plan, a hand-crafted curl request can create
a vocab homework, start a session, submit audio for an item, get phoneme feedback, and complete the
session — proving the whole scoring chain before any UI exists.

Output: Vocab CRUD on the homework module + vocab scoring on the game module, all reusing existing
StorageService, BfaService.analyze, and the GameRepository session machinery.
</objective>

| client→/game/session/:id/vocab-result | Student-uploaded audio + vocabItemId crosses into BFA + DB |
| backend→BFA | Audio buffer forwarded to Azure PA analyze |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-03 | Tampering | /game/session/:id/vocab-result vocabItemId | mitigate | Verify the VocabItem belongs to the session's homework before scoring; reject (400) cross-homework vocabItemId |
| T-08-04 | Spoofing | session submission integrity | mitigate | Endpoint sits behind existing `@UseGuards(AuthGuard)` on GameController; completed-session guard prevents resubmission after completion |
| T-08-05 | Denial of Service | audio upload size | mitigate | FileInterceptor `limits.fileSize: 10MB` (same cap as phonics) rejects oversized uploads |

| T-08-07 | Information Disclosure | image upload path traversal | accept | Reuses existing /homework/image route which generates server-side keys (`Date.now()-random.ext`); originalname is only used for extension, not path — no client-controlled path segment |
| T-08-SC | Tampering | npm installs | mitigate | No new packages in this plan; all imports (@nestjs, prisma) already present — no [ASSUMED]/[SUS]/[SLOP] packages introduced |
