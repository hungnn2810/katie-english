<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser→/game/session/:id/vocab-result | Student-recorded audio + vocabItemId submitted for scoring |
| browser mic→MediaRecorder | Microphone capture in the student's browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-11 | Spoofing | student submits to another student's session | mitigate | saveVocabResult sends Bearer token; backend (08-02) verifies session + vocabItem-belongs-to-homework; student only sees their own startSession id |
| T-08-12 | Information Disclosure | session id in URL | accept | Session ids are sequential ints but gated by AuthGate STUDENT + backend AuthGuard; no PII exposed in the URL |
| T-08-13 | Tampering | malformed/empty audio blob | mitigate | Empty blobs are not appended (size > 0 guard mirrored from savePhonicsResult); backend audio gates (Phase 7) return actionable errors shown as amber messages, never silent 0 |
| T-08-SC | Tampering | npm installs | accept | No new packages — @mui/material, lucide-react already installed; PhonemeChips reused as-is. No [ASSUMED]/[SUS]/[SLOP] packages |
</threat_model>
