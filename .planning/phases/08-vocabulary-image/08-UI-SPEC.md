## Spacing Scale

MUI spacing unit = 8px (MUI default). All `sx={{ ... }}` spacing uses MUI theme multiplier.

| MUI value | Pixels | Usage |
|-----------|--------|-------|
| 0.5 | 4px | Chip gaps, tight icon spacing |
| 1 | 8px | Compact element spacing |
| 2 | 16px | Default element spacing |
| 3 | 24px | Card/section padding |
| 4 | 32px | Page side padding |
| 6 | 48px | Page vertical padding |

**Exceptions:**

| Value | MUI | Justification |
|-------|-----|---------------|
| 12px | 1.5 | Dense row padding inside VocabItemCard — 8px is too tight for the three-column flex layout (drag handle + image zone + word field), 16px creates too much visual weight at the card level |
| 40px | 5 | Major section break between the item list and the save button — 32px blends the two zones visually; 48px (page padding) would imply page-level separation which overstates the relationship |
| 160px × 160px | n/a | Image upload grid cells — fixed by image aspect ratio constraint, not scale-derived |
| 96px diameter | n/a | Record button circle — matches existing speaking homework mic button |
| 8px × 32px | n/a | Progress bar dots — matches existing phonics game pattern |
| 44px min height | n/a | Touch target minimum for all interactive controls in student game |

## Typography

Uses MUI typography system. All `fontSize` values in `sx` prop are pixels as numbers or strings.

**Declared weights: 400 (body/secondary) and 700 (headings, labels, CTAs, display). No other weights are used.**

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px | 400 | 1.5 | Secondary text, captions, student game base size |
| Label | 14px | 700 | 1.4 | Type badges, section headers, button labels, score badges |
| Heading | 24px | 700 | 1.3 | Dialog titles, page headings, card headings |
| Display | 30px | 700 | 1.2 | Game "Ready?" screen heading, "Homework Complete!" |

**Component-local size overrides (outside type scale — excluded from the 4-size count above):**

These values are single-component one-off sizes driven by visual impact requirements. They are NOT part of the global type scale and must not be counted against the 4-size maximum.

| Component | Size | Weight | Notes |
|-----------|------|--------|-------|
| Student game word display (during recording) | 48px | 700 | Large size carries visual impact for word recognition; applies only to the hint chip text during active recording state |
| Score display (results screen) | 72px | 700 | `fontVariantNumeric: 'tabular-nums'`, color from `scoreHexColor()` — outsized size provides display hierarchy on results screen only |

**Phoneme chip labels:** `fontFamily: 'monospace'`, weight 700, size small (MUI Chip size="small").

### Page 2: Teacher — Vocabulary Creation Page

**Route:** `/teacher/homework/create/vocabulary`

**Layout:** Matches `ReadingCreationPage` outer shell — white page background, `maxWidth: 800, mx: 'auto', px: 4, py: 4`.

**Sections (top to bottom):**

1. **Back link** — `← Back to Homework` — `fontSize: 14, color: 'text.secondary'`

2. **Page heading** — `Typography variant="h5"` — `"New · "` in `text.secondary` + `"Vocabulary"` in `#FFB26B` — same pattern as HomeworkModal heading.

3. **Homework name field** — MUI `TextField`, label `"Homework name"`, `fullWidth`, required.

4. **Items section heading** — `Typography variant="caption"` — uppercase — `"ITEMS (UP TO 10)"`.

5. **DnD sortable item list** — `@dnd-kit/core` + `@dnd-kit/sortable`, `verticalListSortingStrategy`. Reuse sensors pattern from `ReadingCreationPage`.

   **Each `VocabItemCard`:**
   - Drag handle (GripVertical icon, 20px, `text.secondary`) — left edge
   - **Image upload zone** — 160px × 160px, `borderRadius: 2`, `border: '2px dashed #E2E8F0'` idle / `border: '2px solid #4F9DFF'` hover
     - Idle: ImageIcon (32px, `text.disabled`) centered + `"Upload image"` caption
     - Uploaded: `<img>` fill zone, `objectFit: 'cover'`, remove overlay on hover
   - **Word label field** — MUI `TextField`, label `"Word"`, `size="small"`, placeholder `"e.g. apple"`, max 32 chars
   - **Remove button** — MUI `IconButton`, X icon (16px), `size="small"`, `color: 'error'`, `aria-label="Remove item {N}"` — right edge
   - Card: MUI `Paper`, `elevation: 1`, `sx: { p: 1.5, display: 'flex', alignItems: 'center', gap: 2, borderRadius: 2 }` (p: 1.5 = 12px dense padding — see Spacing Exceptions)

6. **Add item button** — `Button variant="outlined"`, `startIcon={<Plus size={16} />}`, `"Add Image"`, disabled when item count = 10, full width.

7. **Error Alert** — MUI `Alert severity="error"` — shown inline above save button when validation fails.

8. **Save button** — `Button variant="contained"`, `"Save Vocabulary Homework"`, full width, `size="large"`.

**Validation rules:**
- Minimum 1 item required
- Each item must have both imageUrl (uploaded) and word (non-empty)
- Maximum 10 items

### Page 3: Student — Vocabulary Game

**Route:** `/game/vocab/[id]`

**Theme:** Uses `studentTheme` + `gradients.gameBg` (`#2D0B2E`) full-screen — identical to phonics game.

**State machine (matches existing phonics game):**

| State | What Student Sees |
|-------|------------------|
| `loading` | `CircularProgress` centered on dark bg |
| `mic-check` | "Requesting microphone access…" on dark bg |
| `mic-denied` | Mic icon + "Microphone Required" + "Try Again" button + back link |
| `ready` | Item preview list + "Start Recording" button |
| `playing` | Image display + word hint + record button + phoneme chips (after scoring) |
| `uploading` | `CircularProgress` + "Scoring and saving…" on dark bg |
| `results` | Overall score + per-item result cards with image thumbnails + phoneme chips |
| `error` | "Session not found." + back link |

**Playing state layout (per item):**

```
[ progress dots bar ]          [ N / total ]

[ 280px × 280px image card ]
  border: 4px solid rgba(255,255,255,0.2)
  borderRadius: 16px

[ word hint chip ]             ← shown below image, always visible (D-06 resolved)
  bgcolor: rgba(255,255,255,0.10)
  color: white, fontSize: 16px, fontWeight: 700
  px: 2, py: 0.75, borderRadius: 999px

[ Record button — 96px circle ]
  idle:      border: 4px solid rgba(255,255,255,0.3), Mic icon 40px white
  recording: border: 4px solid #ef4444, pulsing ring, square stop icon
  recorded:  border: 4px solid rgba(52,211,153,0.5), CheckCircle2 40px green

[ phoneme feedback — shown after scoring ]
  PhonemeChips component (reuse as-is)

[ "Next" button / "View Results" button — shown after phoneme chips appear ]
  gradient: gradients.greenSecondary
  px: 4, py: 1.5, borderRadius: 3, fontWeight: 700, fontSize: 18, color: white
```

**Word hint display decision (from CONTEXT.md D-06):** Word label shown as small hint chip below image, always visible. Phoneme chips appear after recording + scoring completes.

**Record flow (per item):**
1. Student taps record button → recording starts (pulsing red ring)
2. Student taps stop → audio uploaded to BFA → phoneme chips appear → "Next" button appears
3. Student taps "Next" → advance to next item
4. After final item → transition to `uploading` → `results`

**Audio error display:** BFA error codes shown as amber `Typography` below image (same `BFA_ERROR_MESSAGES` map from session page). Student can retry recording on error (re-record button appears instead of Next).

## Interaction Contracts

### Image Upload (Teacher Creation)

- **Accept:** `image/*` (PNG, JPG, WebP, GIF)
- **Max size:** 5MB (enforce client-side with error message `"Image must be under 5MB."`)
- **Upload trigger:** Click on upload zone OR drag-and-drop
- **During upload:** Zone shows `CircularProgress` (24px), button disabled
- **After upload:** Image fills zone, `objectFit: 'cover'`. Hover overlay shows `"Remove"` button (white text, semi-transparent dark bg).
- **Error:** Zone border turns red (`error.main`), error text replaces upload caption
- **API:** Reuse `uploadSpeakingImage()` from `admin-api` (same MinIO pattern)

### DnD Reorder (Teacher Creation)

- Sensors: `PointerSensor` + `KeyboardSensor` (reuse from ReadingCreationPage)
- Drag handle cursor: `grab` / `grabbing`
- Dragging item: `opacity: 0.5`, `boxShadow: 6` (MUI elevation shadow)
- Drop zone: no visual indicator — list reorders on drop (matches reading pattern)

### Record Button (Student Game)

- **Idle:** Click starts recording
- **Recording:** Click stops recording, triggers BFA analyze call
- **Analyzing:** Button disabled, `CircularProgress` shown, `"Scoring…"` text
- **After result:** Phoneme chips appear below image, Next/View Results button appears
- **Re-record on BFA error:** "Try Again" button replaces Next button; re-record resets state for this item

### Progress Dots (Student Game)

- One dot per item (matches phonics game pattern)
- Dot sizes: `height: 8px, width: 32px, borderRadius: '9999px'`
- Done: `background: '#ffffff80'`
- Current: `background: '#A78BFA'` (student theme primary)
- Upcoming: `background: '#ffffff20'`
- Transition: `transition: 'all 0.15s'`

### Animation

- **Shake on BFA error:** Use existing `shake` keyframe from `frontend/lib/theme.ts` — apply to image card on error, 400ms ease-in-out
- **fadeIn on phoneme chips:** Use existing `fadeIn` keyframe — `animation: '${fadeIn} 0.25s ease-out'`
- **Record button pulse ring:** `@keyframes ping` (same as speaking homework `'ping 1s cubic-bezier(0,0,0.2,1) infinite'`)

## Accessibility

- All image upload zones: `role="button"`, `aria-label="Upload image for item {N}"`
- Remove item button: `aria-label="Remove item {N}"` — applied to the X IconButton on each VocabItemCard
- Record button: `aria-label="Start recording"` / `"Stop recording"` toggled on state
- Phoneme chips: `data-status` attribute (already on PhonemeChips component)
- Image thumbnails in teacher results: `alt="{word}"` (word label as alt text)
- DnD sortable: keyboard sensor enabled (matches ReadingCreationPage)
- Score badges: `aria-label="{score} percent — {label}"` for screen readers
