   On a 320px screen with 4 image cards at 88px + gaps, they still overflow.
   Per D-08: change image cards to `width: { xs: '45%', sm: 112 }, height: { xs: 'auto', sm: 112 }`.
   Add `aspectRatio: '1'` to maintain square shape when width is percentage.
   The image `<img>` inside already uses `objectFit: 'cover'` with `width: '100%', height: '100%'`
   — when height is auto these need `height: '100%'` removed, use only `width: '100%'`
   and let the aspectRatio on the container control height.
   Actually: keep `height: { xs: 0, sm: 112 }` with `paddingBottom: { xs: '45%', sm: 0 }` is
   complex. Simpler: set `width: { xs: '45%', sm: 112 }, aspectRatio: '1 / 1'` on the Box
   and remove the explicit `height` prop. The `overflow: 'hidden'` keeps img contained.
   The `<img>` inside should use `style={{ width: '100%', height: '100%', objectFit: 'cover' }}`.

2. `PlayingShell` — outer Box already has `px: { xs: 2, sm: 4 }` — correct. The inner
   content area Box uses `px: { xs: 2, sm: 4 }` — already correct.

   responsive (good, no change). The blank span uses `width: { xs: 72, sm: 96 }` — already
