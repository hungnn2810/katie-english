From frontend/app/game/layout.tsx (current SVG — needs fix):
The right-side circles use `cx="420"` (hardcoded pixel value):
```
{[150, 230, 320].map((r) => (
  <circle key={`r${r}`} cx="420" cy="320" r={r} fill="none" stroke="white" strokeWidth="1" />
))}
```
The SVG Box has `width: '100%', height: '100%'`. Fix: use a `<g>` element with
`transform="translate(100%, 320)"` and set each circle to `cx="0" cy="0"`.
This lets the SVG coordinate system move the group to the right edge of the viewport.
Alternatively render the circles with `cx="100%"` directly (supported in SVG 1.1 for
percentage lengths on `cx`/`cy`). Use the `<g transform>` approach as it is more reliable
across browsers.

From frontend/app/game/homework/page.tsx (current structure):
- Outer `PageContent` `<Box sx={{ minHeight: '100vh', position: 'relative', overflow: 'hidden' }}>` — no maxWidth
- Header `<Box component="header" sx={{ px: '18px', py: '14px', ... }}>` — hardcoded px
- Main `<Box component="main" sx={{ px: '18px', pb: '30px' }}>` — hardcoded px
- Greeting `<Typography sx={{ fontSize: 30, ... }}>` — hardcoded fontSize
- Sub-heading `<Typography sx={{ fontSize: 15, ... }}>` — hardcoded fontSize
- Username pill `<Typography sx={{ fontSize: 14, fontWeight: 600 }}>` inside header user pill
- Lock button `<Button sx={{ px: 1, py: 0.75, minWidth: 0 }}>` — py 0.75 = 6px, too small
- Logout button `<Button sx={{ px: 1, py: 0.75, minWidth: 0 }}>` — same

Decision refs: D-02 (maxWidth container), D-03 (padding scale), D-05 (typography scale),
D-06 (SVG fix), D-07 (single-column cards), D-11 (remove minWidth), D-12 (header collapse)
