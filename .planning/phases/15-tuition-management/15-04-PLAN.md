    Create frontend/app/admin/tuition/_components/TuitionReportTable.tsx as a 'use client' component.

    Props: classId (number), month (number), year (number). The classId, month, and year come from the parent page's state — the component does not own the class/month/year selector state, only the status filter.

    State: rows (TuitionReportItem[], default []), loading (boolean default true), statusFilter ('ALL' | 'PENDING' | 'PAID' | 'OVERDUE', default 'ALL').

    On mount and whenever classId/month/year/statusFilter changes (useEffect deps), call getTuitionReport({ classId, month, year, statuses: statusFilter === 'ALL' ? undefined : [statusFilter] }). Show CircularProgress during load. Show error toast on failure.

    Computed totals from rows:
    - totalCollected: rows.filter(r => r.status === 'PAID').reduce sum of totalAmount
    - totalPending: rows.filter(r => r.status === 'PENDING').reduce sum of totalAmount
    - totalOverdue: rows.filter(r => r.status === 'OVERDUE').reduce sum of totalAmount

    Render:
    - Filter row: FormLabel 'Trạng thái' + Select (ALL / PENDING / PAID / OVERDUE in Vietnamese: Tất cả / Chưa đóng / Đã đóng / Quá hạn)
    - Totals summary row (MUI Box flex row): 'Đã thu: {totalCollected.toLocaleString('vi-VN')} VNĐ' (green), 'Chưa thu: {totalPending.toLocaleString('vi-VN')} VNĐ' (amber), 'Quá hạn: {totalOverdue.toLocaleString('vi-VN')} VNĐ' (red) — use MUI Chip or simple styled Box with backgroundColor
    - Table: check if TableShell exists at '@/components/ui/TableShell'; if not, use MUI Table/TableHead/TableBody/TableRow/TableCell directly.
      Columns: Học sinh | Tiền học (VNĐ) | Tiền sách (VNĐ) | Tổng (VNĐ) | Hạn đóng | Trạng thái | Ngày đóng
    - Status badge: PAID → green background '#dcfce7', text '#15803d'; OVERDUE → red '#fee2e2', text '#b91c1c'; PENDING → amber '#fef3c7', text '#92400e'. Use inline style or MUI sx prop, not Tailwind.
    - Ngày đóng column: show new Date(row.paidAt).toLocaleDateString('vi-VN') if paidAt, else '—'
    - Hạn đóng column: new Date(row.dueDate).toLocaleDateString('vi-VN')
    - All VNĐ amounts: .toLocaleString('vi-VN') + ' đ'

    Empty state: if rows.length === 0 after loading, show Typography 'Không có dữ liệu học phí cho tháng này.' centered.

    If TableShell does not exist: use standard MUI Table, TableHead, TableBody, TableRow, TableCell from '@mui/material'.
