## Spacing Scale

Declared values (multiples of 4, expressed in MUI `theme.spacing` units where 1 unit = 8px):

| Token | px Value | MUI spacing() | Usage |
|-------|----------|---------------|-------|
| xs | 4px | 0.5 | Icon gaps, inline text padding |
| sm | 8px | 1 | Compact element spacing, badge padding |
| md | 16px | 2 | Default element spacing, card inner padding |
| lg | 24px | 3 | Section inner padding, between elements |
| xl | 32px | 4 | Layout column gaps, card groups |
| 2xl | 48px | 6 | Between section blocks |
| 3xl | 64px | 8 | Page-level section breaks (desktop) |
| hero | 96px | 12 | Hero section top/bottom padding (desktop) |

Exceptions:
- Mobile section padding collapses from 64px to 32px (hero) and 48px to 24px (standard breaks)
- Touch targets (Zalo CTA button): minimum 44px height
- Testimonial carousel dots: minimum 32px touch area

## Typography

All typography uses Inter font (--font-inter). MUI variant mapping below:

| Role | MUI Variant | Size (desktop) | Size (mobile) | Weight | Line Height | Usage |
|------|-------------|---------------|---------------|--------|-------------|-------|
| Display | h1 | 48px | 32px | 700 | 1.15 | Hero tagline (one instance only) |
| Heading | h2 | 32px | 24px | 700 | 1.2 | Section headings (h2 per section) |
| Subheading | h3 | 20px | 18px | 600 | 1.3 | Card titles, teacher profile sub-labels |
| Body | body1 | 16px | 16px | 400 | 1.6 | All paragraph text, testimonial quotes |
| Label | caption / body2 | 14px | 14px | 500 | 1.4 | Tags, badges, stat labels, CTA sub-copy |

Rules:
- Exactly one `<h1>` on the page (hero tagline).
- Section headings use `<h2>` — one per section.
- Sub-sections and card titles use `<h3>`.
- Body text weight is always 400; heading weights are always 700 (h1/h2) or 600 (h3).
- Vietnamese text: no special font — Inter supports Latin Extended which covers Vietnamese diacritics.

## Section-Specific Interaction Contracts

### Hero Section
- Static layout. No animation on load beyond `fadeIn` (0.4s, already in lib/theme.ts).
- Hero visual: placeholder Box with blue gradient (#4F9DFF → #6ED6C1) until real photo provided.
- No auto-play, no carousel in hero.

### Teacher Profile
- Static card. No hover animation.
- Avatar: `next/image` 200x200px, circular, `alt="Cô Katie — giáo viên tiếng Anh"`.

### Student Results + Testimonials
- Results cards: 2-3 MUI Card components in a grid. Cards show: student name (anonymized or first name), before/after score, achievement badge.
- Testimonials carousel: auto-advances every 5 seconds. Manual prev/next arrow controls. Dot indicators showing position. No external carousel library — use MUI Box + state-driven transform for simplicity. Falls back gracefully if JS disabled (shows first testimonial only).
- Testimonial structure: Avatar (initials), parent name + relation, 2-3 sentence quote, star rating (static, 5 stars).

### Software Section
- Feature list: MUI List with lucide-react icons (CheckCircle2, colored #4F9DFF) + short Vietnamese label per feature.
- Screenshots: MUI Paper wrapper with subtle box-shadow. Images use `next/image` with `width` and `height` declared for LCP.
- Features to highlight (per D-10): quản lý lớp học, giao bài tập số, chấm điểm tự động, theo dõi tiến độ.

### CTA / Contact
- Full-width banner, background #4F9DFF, white text.
- Two elements side by side: Zalo button (links to `https://zalo.me/{number}`) + phone number displayed as `<a href="tel:{number}">`.
- Zalo button: MUI Button variant="contained" with white background, #4F9DFF text, lucide MessageCircle icon.
- Phone: Typography variant="h4", white, displayed below Zalo on mobile.

## Animation Contract

Source: CONTEXT.md D-12 — minimal animation, fade-in on scroll only.

| Animation | Trigger | Duration | Easing | Element |
|-----------|---------|----------|--------|---------|
| fadeIn | On mount (hero only) | 400ms | ease-out | Hero text + visual |
| slideUp | On scroll into viewport (Intersection Observer) | 300ms | ease-out | Section headings, cards |
| auto-advance | Timer, 5s interval | 500ms slide transition | ease-in-out | Testimonial carousel |
| none | — | — | — | All other elements |

No parallax. No float/bounce. No hover scale transforms. Use `opacity` + `transform: translateY` only.

Animation implementation: Use the existing `fadeIn` and `slideUp` keyframes already exported from `lib/theme.ts`. Apply via MUI `sx` prop `animation` property.

## Accessibility Contract

| Requirement | Spec |
|-------------|------|
| Color contrast | All text on white/light background: minimum 4.5:1 (WCAG AA). #0F172A on #F7F9FC = 14.7:1 — passes. #FFFFFF on #4F9DFF = 3.8:1 — acceptable for large text (CTA button). |
| Keyboard navigation | Carousel prev/next arrows focusable; Zalo button focusable; phone link focusable |
| Carousel pause | Carousel auto-advance pauses on hover/focus |
| Touch targets | Zalo button min-height: 44px; carousel arrows min 44x44px |
| Skip link | Not required (no nav menu — single scroll page) |
| Landmark elements | `<main>`, `<header>` (if nav added), `<footer>` for contact |
| Image alt | All images require alt text; decorative images use alt="" |
