## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public internet → Next.js middleware | Host header can be spoofed by reverse proxy; trust is established upstream |
| Browser → /marketing route | Fully public, no auth, no user input |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-01 | Spoofing | middleware.ts detectSubdomain | accept | Root domain detection uses Host header set by CDN/reverse proxy (Vercel/Nginx) — cannot be spoofed by end users in production |
| T-13-02 | Information Disclosure | middleware.ts rewrite | mitigate | Rewrite exposes /marketing route name internally; acceptable since /marketing is public and has no auth-gated content |
| T-13-03 | Tampering | JSON-LD script tag | accept | dangerouslySetInnerHTML used on server-generated static JSON — no user input involved, no XSS risk |
| T-13-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in this plan — all dependencies already in package.json |
</threat_model>
