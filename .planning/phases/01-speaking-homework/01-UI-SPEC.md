# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: speaking-homework (continuation work).
> Generated by gsd-ui-researcher. Consumed by gsd-planner and gsd-executor.

**Scope:** This phase modifies five frontend files:
1. `frontend/app/teacher/homework/page.tsx` — HomeworkModal: SPEAKING type mode selector
2. `frontend/app/game/session/[id]/page.tsx` — Student results screen: FREE_SPEAK image + keyword count
3. `frontend/app/teacher/homework/[id]/page.tsx` — Assignment grouping redesign (already written, commit only)
4. `frontend/app/teacher/homework/[id]/try/page.tsx` — Full rewrite to file-upload flow + "Preview Mode" banner
5. `frontend/app/teacher/homework/[id]/session/[sessionId]/page.tsx` — Mode badge, transcript, score %, video playback (already written)

Backend changes (D-05, D-20–D-24) have no UI surface and are not contracted here.

## Spacing Scale

Pre-existing scale — this phase does not introduce new spacing values.

| Token | Value | Tailwind | Usage in this phase |
|-------|-------|----------|---------------------|
| xs | 4px | gap-1, p-1 | Icon gaps, inline padding |
| sm | 8px | gap-2, p-2 | Badge gaps, tight row spacing |
| md | 16px | p-4, gap-4 | Modal section spacing, card internal padding |
| lg | 24px | p-6, gap-6 | Card outer padding, page section gap |
| xl | 32px | mb-8, py-8 | Major layout gaps |
| 2xl | 48px | py-12 | Page-level vertical centering |
| 3xl | 64px | — | Not used in this phase |

Exceptions:
- Upload dropzone: `py-8 px-4` (32px vertical / 16px horizontal) — matches existing student upload pattern in session page line 411
- Preview Mode banner: `px-4 py-2` (16px/8px) — matches existing banner in try/page.tsx line 252

## Typography

Two weights only across all screens. Child-facing screens (student upload, student results) use larger display sizes.

| Role | Size | Weight | Line Height | Tailwind Classes | Screen |
|------|------|--------|-------------|------------------|--------|
| Display / Score | 72px (text-7xl) | 900 (font-black) | 1.0 | `text-7xl font-black` | Student results score number |
| Heading | 30px (text-3xl) | 900 (font-black) | 1.2 | `text-3xl font-black` | Student upload h2, try-mode h1 |
| Sub-heading | 24px (text-2xl) | 700 (font-bold) | 1.3 | `text-2xl font-bold` | Script text display in upload |
| Body / Label | 14px (text-sm) | 700 (font-bold) | 1.5 | `text-sm font-bold` | Teacher modal labels, badge text |
| Caption | 12px (text-xs) | 700 (font-bold) | 1.0 | `text-xs font-bold` | Section headers (uppercase tracking-wide), mode selector descriptions |

Heading sizes on teacher-facing pages (modal, detail page, session detail) stay at `text-base font-bold` (16px/700) — matches existing teacher portal conventions (`session/[sessionId]/page.tsx` line 91, `[id]/page.tsx` line 86).

```

- FREE_SPEAK: `"Keywords (comma-separated)"` — e.g. `"cat, sits, mat"`
- SCRIPT_MATCH: `"Target text"` — full sentence/phrase

    gradients.primaryPurple
    onClick: router.push(`/teacher/homework/${hwId}`)

**State: 'error'**
```
min-h-screen flex flex-col items-center justify-center gap-4, background: gradients.gameBg

    Copy: "Homework not found." (load error) or "Scoring failed. Please try again." (upload error)
  Back button: text-white/60 text-sm hover:text-white → "← Back"
