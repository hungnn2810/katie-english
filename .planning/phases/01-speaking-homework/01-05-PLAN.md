<objective>
Deliver the teacher try-mode feature end-to-end so teachers experience exactly what students do — file upload, real WhisperX transcription, real calcFreeSpeak / calcSpeakingScore — without creating any database session.

Three coordinated layers:

1. **Backend endpoint (D-13):** Add `POST /game/homework/:id/try-speak` to `GameController`, mirroring the existing `saveSpeakingResult` endpoint pattern (FileInterceptor on field 'audio', 100MB cap, AuthGuard inherited from class).

2. **Backend service (D-14):** Add `trySpeakingHomework(homeworkId, audioBuffer?, mimeType?)` to `GameService`. The method:
   - Loads the Homework directly via `PrismaService` (no session — the existing GameModule already imports PrismaModule).
   - Validates type === 'SPEAKING' and speakingText is non-null.
   - Calls `BfaService.transcribe()` if audio is provided (try/catch + logger.warn pattern matching `saveSpeakingResult`).
   - Dispatches to `calcFreeSpeak` (FREE_SPEAK) or `calcSpeakingScore` (SCRIPT_MATCH).
   - Returns the score payload + speakingMode + speakingPictureUrl WITHOUT touching the DB.

3. **Frontend rewrite (D-15):** Replace the entire current try page (currently a full camera + SpeechRecognition implementation with local levenshtein) with a file-upload page mirroring the student session upload screen. Add a permanent "Preview Mode — Results not saved" banner. Add a `trySpeakingHomework` helper to `frontend/lib/admin-api.ts`.

Purpose:
- Honors D-13 (file-upload only, no MediaRecorder), D-14 (real BFA scoring, not local approximation), D-15 (no session created).
- Closes the last decision gap in Phase 1.
- Reuses existing patterns (FileInterceptor, AuthGate, gradient backgrounds, scoreHexColor) for visual consistency with the student flow.

Output:
- `backend/src/game/game.controller.ts` with one new `@Post('homework/:id/try-speak')` endpoint.
- `backend/src/game/game.service.ts` with one new `trySpeakingHomework` method + PrismaService injection.

- `frontend/app/teacher/homework/[id]/try/page.tsx` fully rewritten (~150 lines, down from current ~330 lines of camera+speech code).
- A single commit landing all four files with a `feat(01-05): teacher try mode — file upload + real BFA scoring (D-13/D-14/D-15)` message.

   ```
   async trySpeakingHomework(hwId: number, audioBuffer?: Buffer, mimeType?: string) {
     const hw = await this.prisma.homework.findUnique({
       where: { id: hwId },
       select: {
         type: true,
         speakingMode: true,
         speakingText: true,
         speakingPictureUrl: true,
       },
     });
     if (!hw) throw new NotFoundException(`Homework ${hwId} not found`);
     if (hw.type !== 'SPEAKING') throw new BadRequestException('Homework is not a SPEAKING type');
     if (!hw.speakingText) throw new BadRequestException('Homework has no speaking text');

     let transcribedText = '';
     if (audioBuffer && audioBuffer.length > 0) {
       try {
         const result = await this.bfa.transcribe(audioBuffer, mimeType ?? 'audio/webm');
         transcribedText = result.text;
         this.logger.log(`[try-speak hw=${hwId}] WhisperX: "${transcribedText}"`);
       } catch (err) {
         this.logger.warn(`[try-speak hw=${hwId}] WhisperX error: ${(err as Error).message}`);
       }
     }

     const { score, matchedWords, totalWords } = hw.speakingMode === 'FREE_SPEAK'
       ? calcFreeSpeak(transcribedText, hw.speakingText)
       : calcSpeakingScore(transcribedText, hw.speakingText);
     this.logger.log(`[try-speak hw=${hwId}] score=${score} matched=${matchedWords}/${totalWords} mode=${hw.speakingMode ?? 'SCRIPT_MATCH'}`);

     return {
       score,
       matchedWords,
       totalWords,
       transcribedText,
       speakingMode: hw.speakingMode,
       speakingPictureUrl: hw.speakingPictureUrl,
     };
   }
   ```
