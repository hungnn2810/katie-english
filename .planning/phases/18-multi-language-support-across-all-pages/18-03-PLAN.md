## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-06 | Injection (XSS) | `t('modal.editTitle', { name })` where `name` is teacher-entered class/student name | accept | next-intl's ICU interpolation returns a string that React renders as a text child (no `dangerouslySetInnerHTML`); standard JSX escaping neutralizes any HTML-like characters in `name`. Same protection already applies to the pre-existing unTranslated template literal this replaces. |
| T-18-07 | Tampering | `messages/{en,vi}/teacher.json` `classes`/`students` keys | accept | Static, build-time JSON; not runtime-writable. |
</threat_model>
