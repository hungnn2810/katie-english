# Phase 12 — UI Design Contract

> Visual and interaction contract for Phase 12: Multi-Subdomain Split.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

**Scope reminder:** No new features. Three net-new UI surfaces only:
1. Student login page (`student.*/login`) — class code + name auth flow
2. 403 Access Denied page — wrong role hit wrong subdomain
3. 404 Unknown Subdomain page — unrecognized subdomain (D-09)

Admin login (`admin.*/login`) and Teacher login (`app.*/login`) already exist and require routing adjustments only — no visual redesign.

## Spacing Scale

MUI spacing unit = 8px (`theme.spacing(1) = 8px`). All spacing expressed as MUI `sx` multiples.

| Token | MUI sx | px equiv | Usage |
|-------|--------|----------|-------|
| xs | 0.5 | 4px | Icon gaps, inline padding |
| sm | 1 | 8px | Compact element spacing |
| md | 2 | 16px | Default form field gap |
| lg | 3 | 24px | Section spacing within panel |
| xl | 4 | 32px | Panel internal padding (p: 4) — matches existing login pattern (p: 6 = 48px for left panel) |
| 2xl | 6 | 48px | Left panel padding — matches existing admin/teacher login (p: 6) |
| 3xl | 8 | 64px | Logo-to-headline gap in left panel (mb: 8) — matches existing |

Exceptions:
- Left panel width: 420px fixed (matches existing login pages exactly)
- Right panel form container: maxWidth 448px (matches existing)
- Minimum viewport width: 1024px (`minWidth: 1024` on root Box — matches existing)
- Touch targets: not applicable — laptop/PC only (Phase 4 D-01)
- form-gap | 2.5 (20px) | Form field stack gap — MUI TextField spacing convention

## Typography

MUI Typography using Inter font. Values match established patterns in existing login pages.

Body text weight (MUI default 400) is inherited from the MUI theme and not declared explicitly.

| Role | MUI variant / sx fontSize | Weight | Line Height | Usage |
|------|--------------------------|--------|-------------|-------|
| Display | `fontSize: 36, fontWeight: 900` | 900 | 1.15 | Left panel headline (matches admin/teacher login) |

Letter spacing: `-0.02em` on all Display and Heading text (matches existing). No letter spacing on body. Status labels (403/404 numbers) use `letterSpacing: '0.1em'` — applied via sx, not a separate size declaration.

## Surface Specifications

### Surface 1: Student Login Page (`student.*/login`)

**Layout:** Split panel — identical structural pattern to existing admin and teacher login pages.

```
[ Left panel 420px fixed ]  [ Right panel flex:1 ]
  Dark navy #0C1220           White #FFFFFF
  p: 6 (48px)                 flex center, p: 6
  Logo top                    maxWidth 448px form
  Headline + tagline
  Feature list bottom
```

**Left panel content:**
- Logo: `K` monogram in 40x40 `#A78BFA` box (borderRadius: 2), "Katie English" at fontSize 18, fontWeight 600
- Headline: `"Play & Learn"` (fontSize 36, fontWeight 900, white, lineHeight 1.15) + `"English"` in `#A78BFA` accent span
- Tagline: "Complete your homework and master English pronunciation." (fontSize 14, color `#94A3B8`, lineHeight 1.6, maxWidth 280)
- Feature list (3 items, each with 32x32 purple icon box + description text):
  - `BookOpen` icon — "Complete homework assignments"
  - `Mic` icon — "Practice speaking and phonics"
  - `Star` icon — "See your scores instantly"

**Right panel — form:**
- Heading: "Student Login" (fontSize 24, fontWeight 900)
- Subtitle: "Enter your class code and name to continue" (fontSize 14, `#64748B`)
- Fields (vertical stack, gap: 2.5):
  1. TextField `label="Class Code"` — type text, size small, placeholder "e.g. CLASS-2024", required, fullWidth
  2. TextField `label="Your Name"` — type text, size small, placeholder "Your full name", required, fullWidth
- Error state: MUI Alert severity="error" below fields
- CTA button: `"Enter Class"` — variant contained, bgcolor `#A78BFA`, full width, py: 1.5, borderRadius: 1, fontWeight 600, hover opacity 0.9
- Loading state CTA label: `"Joining..."`

**Interaction states:**
- Submit: disabled + label "Joining..." during loading
- Error: Alert renders below second field, inline (no redirect)
- Success: router.push(`/game/homework`) — no redirect to other subdomain

**No registration link.** No forgot-password link. Students are pre-enrolled by teacher (per CONTEXT.md — auth flow is class code + name, not email + password).

### Surface 2: 403 Access Denied Page

Shown when middleware detects a valid JWT for the wrong role hitting the wrong subdomain (D-04). No cross-subdomain redirect (D-04 locked).

**Layout:** Single centered panel on `#F7F9FC` background. No split panel. Full viewport, `display: flex, alignItems: center, justifyContent: center`.

**Content block (maxWidth 480px, text centered):**
- Icon: `ShieldOff` (Lucide, 48px) in a 80x80 circle, bgcolor `rgba({role-accent},0.12)`, icon color = role accent
- Status label: `"403"` (fontSize 14, fontWeight 600, color role-accent, letterSpacing 0.1em)
- Heading: `"You don't have access to this area"` (fontSize 24, fontWeight 900, color `#0F172A`)
- Body: `"You're signed in with a different role. Please go to the correct login page for your account."` (fontSize 14, color `#64748B`, lineHeight 1.6)
- CTA: `"Go to Login"` — MUI Button variant="contained", bgcolor = role accent, href = `/login` (on current subdomain), fontWeight 600, borderRadius 1, px: 4, py: 1.5

**Role-specific accent:** The page reads which subdomain it is on and uses that subdomain's accent color for the icon circle and button:
- `admin.*` → `#4F9DFF`
- `app.*` → `#F0623A`
- `student.*` → `#A78BFA`

**No back button.** No cross-subdomain links. Copy is from CONTEXT.md D-04.

### Surface 3: 404 Unknown Subdomain Page

Shown when middleware encounters an unrecognized subdomain (D-09). Rendered as a Next.js 404 page.

**Layout:** Identical structure to 403 page — centered single panel on `#F7F9FC`.

**Content block (maxWidth 480px, text centered):**
- Icon: `Globe` (Lucide, 48px) in 80x80 circle, bgcolor `rgba(79,157,255,0.12)`, icon color `#4F9DFF` (neutral blue — no role context)
- Status label: `"404"` (fontSize 14, fontWeight 600, color `#4F9DFF`, letterSpacing 0.1em)
- Heading: `"Page not found"` (fontSize 24, fontWeight 900, color `#0F172A`)
- Body: `"This address isn't recognized. Use one of the links below to reach the right place."` (fontSize 14, color `#64748B`, lineHeight 1.6)
- Link set (MuiLink or Button variant="text", stacked, gap: 1):
  - "Teacher login" → `https://app.katie-english.com.vn/login`
  - "Student login" → `https://student.katie-english.com.vn/login`
  - "Admin login" → `https://admin.katie-english.com.vn/login`

**No full-page dark panels.** No branding left panel. Minimal, informative.

## Implementation Notes for Executor

1. **Student login auth flow:** POST to `/game/auth/login` (or equivalent student session endpoint in `backend/src/game/game.controller.ts`) with `{ classCode, name }`. On success, set `student-token` cookie (D-06). On failure, show inline error — no redirect.

2. **Cookie name:** `student-token` (D-06). Must match what middleware reads. Do not reuse `teacher-token` or `admin-token`.

3. **403 page placement:** `frontend/app/403/page.tsx` (or as a special route the middleware redirects to). Must NOT require authentication — it is shown to unauthenticated or wrong-role users.

4. **404 page placement:** Next.js `frontend/app/not-found.tsx` — middleware returns 404 for unrecognized subdomains (D-09).

5. **Student login placement:** `frontend/app/login/page.tsx` will serve `student.*/login` via middleware rewrite (D-03, D-10). The existing combined Teacher+Student toggle login at this path needs to be replaced with the dedicated student-only form described in Surface 1 above. Teacher login moves to its own page at `frontend/app/teacher-login/page.tsx` or remains at `/login` on `app.*` subdomain only (executor to confirm with planner).

6. **ThemeProvider:** Student login page must be wrapped in `studentTheme` ThemeProvider (same as `/game/**` layout) to get `#A78BFA` as the primary color and rounder 6px border radius.

7. **minWidth 1024:** All three new surfaces must include `style={{ minWidth: 1024 }}` on the root Box, matching existing pages.
