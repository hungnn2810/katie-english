# Phase 4 — UI Design Contract

> Visual and interaction contract for Phase 4: student-ux-polish.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

**Scope note:** This phase changes exactly ONE file — `frontend/app/game/homework/page.tsx`.
Changes are limited to: (1) sorting assignments by endDate ascending, and (2) adding an
"Overdue" badge variant for assignments where daysLeft < 0. No layout, spacing, or
typographic changes are introduced. All tokens below are pre-existing and are documented
here as the contract that must not drift.

All sizes are pre-existing in the component. No new type styles introduced.

Two weights only: 900 (font-black) reserved for the page heading; 700 (font-bold) used for
all other text roles. Body/subheading weight consolidated from font-semibold (600) to
font-bold (700) to satisfy the 2-weight maximum.

## Color

All tokens are from `frontend/tailwind.config.js` and `frontend/lib/colors.ts`.

| Role | Token | Hex | Usage |
|------|-------|-----|-------|
| Dominant (60%) | gameBg gradient | #1E1B4B → #4338CA | Full page background (game screen) |
| Secondary (30%) | card gradient cycle | cardGradients[i % 6] | Homework assignment cards |
| Accent (10%) | highlight | #FF7B7B | Overdue badge, Due-today badge, error borders |
| Score positive | brand-green | #7BD88F | Best score badge (completed assignments) |
| Destructive | highlight | #FF7B7B | Password error, general error state |

**Accent reserved for:**
- "Overdue" badge background (D-04 — NEW in this phase)
- "Due today" badge background (existing, daysLeft === 0)
- Error state background tint and border (`bg-highlight/20 border-highlight/60`)
- Password form error text

The `highlight` token (#FF7B7B) is the single semantic color for urgency/error in this UI.
It must NOT be used for neutral informational elements.

## Badge Variants — Complete State Machine

This table is the canonical reference for the badge logic in this phase.

| Condition | Badge Text | Tailwind Classes | Notes |
|-----------|-----------|------------------|-------|
| bestScore !== null | `Best: {score}%` | `text-xs font-bold px-3 py-1 rounded-full bg-brand-green text-white` | Shown instead of due-date badge |
| daysLeft < 0 | `Overdue` | `text-xs font-bold px-3 py-1 rounded-full bg-highlight text-white` | NEW — D-04. Static display, no animation. |
| daysLeft === 0 | `Due today` | `text-xs font-bold px-3 py-1 rounded-full bg-highlight text-white` | Existing |
| daysLeft === 1 | `1 day left` | `text-xs font-bold px-3 py-1 rounded-full bg-highlight text-white` | Existing (daysLeft <= 1 branch) |
| daysLeft > 1 | `{N} days left` | `text-xs font-bold px-3 py-1 rounded-full bg-white bg-opacity-20 text-white` | Existing neutral badge |

**Animation decision (Claude's Discretion, CONTEXT.md):** Static display. No pulse or blink
animation on the Overdue badge. The red color (#FF7B7B) provides sufficient visual urgency
without motion that could distract young students during a lesson.
