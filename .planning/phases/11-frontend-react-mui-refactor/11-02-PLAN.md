## Task 1 — Create frontend/components/ui/ directory

Create four files. All use MUI components (Box, Typography, Card from @mui/material).
Import Lucide icons from lucide-react.

## Task 2 — StatCard.tsx

Props: `icon: LucideIcon, value: string | number, label: string, color: string, bgColor: string`

Layout:
- MUI Card, sx: padding: '22px', cursor: 'pointer', '&:hover': { transform: 'translateY(-2px)', boxShadow: '0 4px 12px rgba(15,23,42,0.10)' }, transition: 'all 0.2s'
- Top row flex between: icon well (44×44, borderRadius: '12px', background: bgColor, display flex center) + ArrowRight icon (size 16, color #94A3B8)
- Value: Typography sx={{ fontSize: 30, fontWeight: 900, letterSpacing: '-0.03em', color, mt: 2.25, mb: 0.5 }}
- Label: Typography sx={{ fontSize: 14, color: '#64748B', fontWeight: 500 }}

## Task 3 — HwTypeChip.tsx

Props: `type: 'PHONICS' | 'SPEAKING' | 'VOCABULARY' | 'LISTEN' | 'READING'`

Config map:
```typescript
const CONFIG = {
  PHONICS:    { label: 'Phonics',    bg: '#FFF7ED', color: '#F97316', Icon: Hash },
  SPEAKING:   { label: 'Speaking',   bg: '#FDF2F8', color: '#EC4899', Icon: Mic },
  VOCABULARY: { label: 'Vocabulary', bg: '#F5F3FF', color: '#8B5CF6', Icon: ImageIcon },
  LISTEN:     { label: 'Listen',     bg: '#ECFEFF', color: '#06B6D4', Icon: Headphones },
  READING:    { label: 'Reading',    bg: '#F0FDF4', color: '#16A34A', Icon: BookOpen },
}
```

Render MUI Chip with:
  sx: borderRadius: '999px', fontWeight: 700, fontSize: 12, bgcolor: config.bg, color: config.color
  icon prop: config.Icon at size 12

## Task 4 — PageHeader.tsx

Props: `breadcrumb?: string[], title: string, subtitle?: string, portal: string`

breadcrumb = [portal, ...breadcrumb]. Render as: `Portal › Page › Sub` with › separator.
Title: Typography sx={{ fontSize: 26, fontWeight: 900, color: '#0F172A', letterSpacing: '-0.03em', lineHeight: 1 }}
Subtitle: Typography sx={{ fontSize: 14, color: '#64748B', mt: 1 }}
Wrap in Box sx={{ mb: 3 }}

## Task 5 — TableShell.tsx

Props: `columns: { label: string; width: string }[], children: React.ReactNode`

Render:
- MUI Card sx={{ overflow: 'hidden' }}
- Header Box: sx={{ display: 'grid', gridTemplateColumns: columns.map(c => c.width).join(' '), px: '22px', py: '12px', bgcolor: '#F8FAFC', borderBottom: '1px solid #E2E8F0' }}
- Each header cell: Typography sx={{ fontSize: 11, fontWeight: 700, textTransform: 'uppercase', letterSpacing: '0.06em', color: '#94A3B8' }}
- {children} below (rows provided by parent)

Export a TableRow helper:
Props: `columns: same, cells: React.ReactNode[], last?: boolean`
Render Box sx={{ display: 'grid', gridTemplateColumns, px: '22px', py: '14px', borderBottom: last ? 'none' : '1px solid #E2E8F0', alignItems: 'center' }}
Each cell: Box sx={{ fontSize: 14 }}
