## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NestJS backend → Python BFA service | Internal HTTP call (Docker network); BFA service trusts caller for `word`/`expected_phonemes` content but enforces size limits. |
| BFA service → ffmpeg / espeak-ng subprocesses | Subprocess invocation; user-controlled `audio` bytes piped to ffmpeg via temp file. |
| Client browser → uploaded audio | Untrusted bytes, already validated upstream at NestJS multipart parser; BFA additionally enforces `MAX_UPLOAD_BYTES` and `MAX_EXPECTED_PHONEMES`. |
