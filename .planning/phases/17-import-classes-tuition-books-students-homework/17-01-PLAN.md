    @Injectable() class ImportService, constructor injects PrismaService.

    Private method parseSheet(workbook: XLSX.WorkBook, sheetName: string): Record<string, unknown>[]:
    - Guard: if (!workbook.Sheets[sheetName]) return []
    - Call XLSX.utils.sheet_to_json(sheet, { defval: '' }) — defval normalizes missing cells
    - XLSX.read must be called with { type: 'buffer', cellDates: true } — see Pitfall 1 in RESEARCH.md

    Private method parseClassesSheet(rows): ClassRow[] — map raw rows to typed objects: name (string), code (string, optional), startDate (Date via new Date(row.startDate)), endDate (Date), scheduleSlots (string, comma-separated days), pricePerSession (number | undefined), bookFee (number | undefined), dueDayOfMonth (number | undefined).

    Private method parseStudentsSheet(rows): StudentRow[] — map: fullname, sex ('M'|'F'), dateOfBirth (Date), className, parentName (optional), parentPhone (optional), parentType ('FATHER'|'MOTHER', optional).

    Private method parseHomeworkSheet(rows): HomeworkRow[] — map: homework_name, part_name, word_text, word_highlight (optional).

    Private method groupHomeworkRows(rows: HomeworkRow[]): Map<string, Map<string, HomeworkRow[]>> — preserves insertion order (use Map, not object) so part order is stable.

    Private method parseScheduleSlots(slotsStr: string): { dayOfWeek: number; startTime: string; endTime: string }[]:
    - DAY_MAP: { sun: 0, mon: 1, tue: 2, wed: 3, thu: 4, fri: 5, sat: 6 } (lowercase keys)
    - Split slotsStr by comma, trim each, lowercase, lookup dayOfWeek
    - Return array of { dayOfWeek, startTime: '', endTime: '' }
    - Skip unknown day abbreviations silently (return empty slot for that entry is acceptable)

    Private method generateClassCode(): string — return 'CLS' + Date.now().toString(36).toUpperCase() — used when row.code is blank.

    Private method validateAll(classRows, studentRows, homeworkRows, existingClassNames: Set<string>, existingStudentKeys: Set<string>): ImportError[]:
    - For each classRow: required fields = name, startDate, endDate. Check name not in existingClassNames AND not already seen in this batch (in-file duplicate). Check startDate/endDate are valid dates (isNaN check). If pricePerSession present, also require dueDayOfMonth (1-31 range).
    - For each studentRow: required fields = fullname, sex (M/F only), dateOfBirth, className. Check className exists in classRows[].name OR existingClassNames. Check student key (fullname + '|' + className) not in existingStudentKeys AND not duplicate in this batch. Check sex is 'M' or 'F'. If parentPhone present but parentType absent, add error.
    - For each homeworkRow: required fields = homework_name, part_name, word_text.
    - All errors are collected (never throw) — return complete ImportError[].

    Public async method processUpload(buffer: Buffer, user: { id: number; role: string }): Promise<ImportResult | ImportErrorResult>:
    1. Check buffer — XLSX.read with { type: 'buffer', cellDates: true }
    2. Parse three sheets using parseSheet — each returns [] if sheet absent (D-04)
    3. Validate: fetch existing class names (prisma.class.findMany({ select: { name: true } })) and existing student keys (prisma.student.findMany({ select: { fullname: true, classId: true }, include: { class: { select: { name: true } } } }))
    4. Call validateAll — if errors.length > 0 return { errors } immediately (D-06) — do NOT call prisma.$transaction
    5. Call prisma.$transaction(async (tx) => { ... }):
       - Create classes: for each classRow, auto-generate code if blank, parse scheduleSlots, tx.class.create({ data: { name, code, startDate, endDate, scheduleSlots: JSON.parse/array, teacherId: user.role === 'TEACHER' ? user.id : null, status: 'PENDING' } }). If pricePerSession present, tx.tuitionConfig.create({ data: { classId: cls.id, pricePerSession, bookFee: bookFee ?? null, dueDayOfMonth } }). Build classMap (name -> id).
       - Create students: resolve classId from classMap (in-file class) or DB lookup. tx.student.create({ data: { fullname, sex: sex === 'M' ? 'MALE' : 'FEMALE', dateOfBirth, classId } }). If parentName present, tx.parentInfo.create({ data: { studentId: student.id, name: parentName, phoneNumber: parentPhone, type: parentType === 'FATHER' ? 'FATHER' : 'MOTHER' } }).
       - Create homework: for each [hwName, partsMap] of groupHomeworkRows(homeworkRows): tx.homework.create({ data: { type: 'PHONICS', name: hwName } }). Iterate partsMap with partOrder counter starting at 1: tx.homeworkPart.create({ data: { homeworkId: hw.id, name: partName, order: partOrder++ } }). Iterate words with wordOrder counter starting at 1: tx.homeworkWord.create({ data: { partId: part.id, text: word.word_text, highlight: word.word_highlight || null, order: wordOrder++ } }).
    6. Return { imported: { classes: classRows.length, students: studentRows.length, homework: homeworkGroups.size } }

    Public method generateTemplate(): Buffer:
    - Create workbook with XLSX.utils.book_new()
    - Classes sheet: one example row { name: 'Lớp A', code: 'LA01', startDate: '2026-01-01', endDate: '2026-06-30', scheduleSlots: 'Mon,Wed,Fri', pricePerSession: 100000, bookFee: 50000, dueDayOfMonth: 5 }
    - Students sheet: one example row { fullname: 'Nguyễn Văn A', sex: 'M', dateOfBirth: '2018-05-10', className: 'Lớp A', parentName: 'Nguyễn Văn B', parentPhone: '0912345678', parentType: 'FATHER' }
    - Homework sheet: two example rows { homework_name: 'Bài âm er', part_name: 'Part 1: er', word_text: 'her', word_highlight: 'er' } and { homework_name: 'Bài âm er', part_name: 'Part 1: er', word_text: 'bird', word_highlight: 'ir' }
    - Append each sheet with XLSX.utils.book_append_sheet(wb, XLSX.utils.json_to_sheet(data), sheetName)
    - Return XLSX.write(wb, { type: 'buffer', bookType: 'xlsx' }) as Buffer

    Key pitfall mitigations (RESEARCH.md):
    - Pitfall 1: always pass { cellDates: true } to XLSX.read
    - Pitfall 2: build importedClassNames Set from classRows during validation, check it alongside existingClassNames
    - Pitfall 3: guard with if (!sheet) return [] before sheet_to_json
    - Pitfall 4: use partOrder and wordOrder counters per homework group
    - Pitfall 5: write { dayOfWeek, startTime: '', endTime: '' } directly — do not use DTO ScheduleSlot format

    @Controller('import') @UseGuards(TeacherOrAdminGuard) class ImportController.
    Constructor injects ImportService.

    @Post('upload') endpoint:
    - @UseInterceptors(FileInterceptor('file', { limits: { fileSize: 10 * 1024 * 1024 } }))
    - @UploadedFile() file?: Express.Multer.File, @Req() req: Request
    - Guard: if (!file) throw new BadRequestException('No file uploaded')
    - Guard: if (!file.originalname.endsWith('.xlsx')) throw new BadRequestException('Only .xlsx files are accepted')
    - const user = (req as any).user — contains { id, role } from JWT
    - return this.importService.processUpload(file.buffer, user)

    @Get('template') endpoint:
    - @Res() res: Response (import Response from 'express')
    - const buffer = this.importService.generateTemplate()
    - res.setHeader('Content-Type', 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet')
    - res.setHeader('Content-Disposition', 'attachment; filename="import-template.xlsx"')
    - res.end(buffer)
    - Return type: void (NestJS passthrough is not needed since we use @Res())

    Both endpoints protected by TeacherOrAdminGuard via @UseGuards on the class level (not per-method).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → POST /import/upload | Untrusted .xlsx file content crosses here; attacker could craft malicious archive |
| JWT → TeacherOrAdminGuard | Token must be valid and role must be TEACHER or ADMIN |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Tampering | POST /import/upload xlsx parsing | mitigate | xlsx SheetJS does not execute macros or run embedded scripts; fileSize limit 10MB set in FileInterceptor to prevent zip-bomb DoS |
| T-17-02 | Elevation of Privilege | POST /import/upload, GET /import/template | mitigate | TeacherOrAdminGuard applied at class level — both endpoints require valid JWT with TEACHER or ADMIN role |
| T-17-03 | Tampering | Path traversal via uploaded filename | accept | File buffer is processed in memory only; originalname is checked for extension but never passed to fs operations — no path traversal possible |
| T-17-04 | Tampering | Mass assignment via import (arbitrary classId injection) | mitigate | ImportService whitelists specific columns and derives classId from classMap (name-based lookup), never from raw row data |
| T-17-SC | Tampering | npm install xlsx | mitigate | Package audited in RESEARCH.md Package Legitimacy Audit as Approved (SheetJS, Apache-2.0, 11 years old, github.com/SheetJS/sheetjs) |
</threat_model>
