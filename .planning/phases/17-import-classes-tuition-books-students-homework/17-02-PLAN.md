    Export async function uploadImportFile(file: File, role: 'admin' | 'teacher'): Promise<ImportResponse>:
    - Create FormData: formData.append('file', file)
    - Get token synchronously: const token = role === 'admin' ? getAdminToken() : getToken()

    - If !res.ok: parse error JSON and throw Error with message from response

    Export async function downloadTemplate(role: 'admin' | 'teacher'): Promise<void>:
    - Get token synchronously: const token = role === 'admin' ? getAdminToken() : getToken()
    - fetch(`${API_URL}/import/template`, { headers: { Authorization: `Bearer ${token}` } })
    - If !res.ok: throw Error('Failed to download template')
    - const blob = await res.blob()
    - const url = URL.createObjectURL(blob)
    - Create element: const a = document.createElement('a'); a.href = url; a.download = 'import-template.xlsx'; a.click()
    - URL.revokeObjectURL(url) — cleanup

    Export helper function isImportError(response: ImportResponse): response is ImportErrorResult:
    - return 'errors' in response

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → import-api.ts → POST /import/upload | Admin/teacher JWT must be in Authorization header; file is FormData |
| Browser → import-api.ts → GET /import/template | JWT required; response is a binary blob for download |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-05 | Information Disclosure | GET /import/template response (blob) | accept | Template is public-schema data (column headers and example rows only); no sensitive data in template |
| T-17-06 | Spoofing | Admin/teacher JWT in Authorization header | mitigate | getAdminToken() and getToken() are synchronous localStorage reads (string or null) — same pattern as all other admin/teacher API calls in the project; backend validates JWT signature |
| T-17-07 | Tampering | Error table rendering | accept | Error data comes from the backend's own validation — rendered into MUI Table cells with no dangerouslySetInnerHTML; XSS risk is negligible |
</threat_model>
